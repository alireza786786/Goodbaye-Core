# V2Ray Smart Collector — v4.0

جمع‌آوری کانفیگ از منابع شما → dedup دقیق → تست شبکه → **تست واقعی Xray (پینگ/سرعت واقعی)**
→ فیلتر پینگ < 500ms → بازنویسی نام کانال روی **همهٔ** پروتکل‌ها (شامل vmess) → خروجی txt با
هدر زیبا و زمان زنده → ارسال به کانال تلگرام.

## اجرا در گیت‌هاب (پیشنهادی)

1. همهٔ فایل‌های این ریپو را push کنید.
2. در ریپو: `Settings → Secrets and variables → Actions` → دو Secret بسازید:
   - `BOT_TOKEN` — توکن ربات تلگرام
   - `CHAT_ID` — شناسهٔ کانال/چت مقصد (مثلاً `@channel` یا عدد منفی)
3. به تب Actions بروید و **Run workflow** را بزنید (یا صبر کنید تا زمان‌بندی هر ۶ ساعت اجرا شود).

خروجی `subscription_part*.txt` هم به‌صورت Artifact ذخیره می‌شود و هم در خود ریپو commit
می‌شود — کاربران می‌توانند از لینک raw هم بگیرند:

```
https://raw.githubusercontent.com/<user>/<repo>/main/subscription_part1.txt
```

## تنظیمات (متغیر محیطی)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BOT_TOKEN` | — | توکن ربات (فقط در GitHub Secrets؛ هرگز در کد) |
| `CHAT_ID` | — | شناسهٔ کانال مقصد |
| `XRAY_ARCH` | `Xray-linux-64.zip` | معماری باینری Xray (گوشی: `Xray-linux-arm64-v8a.zip`) |

## منابع

مخزن شما: فایل `sources.txt` — هر خط یک URL، `#` برای نظر. اگر منبعی دانلود نشود، اجرا
متوقف نمی‌شود و به بعدی می‌رود. اگر `sources.txt` نباشد، فهرست پیش‌فرض ۳۶ منبع داخل کد استفاده می‌شود.

## تست

```bash
pip install -r requirements.txt pytest
pytest
```

## اجرا در Termux

```bash
bash run.sh      # معماری arm64 را خودکار تشخیص می‌دهد
```
